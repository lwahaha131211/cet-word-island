## 二、源代码文档

### 2.1 官方格式要求

1. 提交源程序的前、后各连续 30 页，共 60 页；
2. 每页不少于 50 行（结束页除外）；
3. 页眉注明软件名称、版本号与页码；
4. 页码连续，不得跳页；
5. 代码需与软件实际运行版本一致；
6. 不得出现与软件无关的内容、广告或空白页。

### 2.2 本项目导出方法

项目已提供导出脚本：

```bash
cd cet-word-island-miniprogram
node tools/export-source.js
```

脚本会生成：

- `docs/源代码-全量.txt`：原创源代码（约 1.88 万行，按 50 行/页约 398 页，不含第三方词库数据），用于存档与查重；
- `docs/源代码-软著提交版.html`：自动截取前 30 页 + 后 30 页，每页 50 行，页眉含软件名称、版本与页码。

### 2.3 转成 PDF

1. 使用 Chrome / Edge 打开 `docs/源代码-软著提交版.html`；
2. `Ctrl + P` 打开打印；
3. 纸张选择 **A4**，边距选择 **默认**，缩放 **100%**；
4. 关闭「页眉和页脚」（文档自带页眉，避免重复）；
5. 另存为 PDF，检查是否为 **60 页**、每页 **50 行**；
6. 文件名建议：`词灵岛四六级英语学习软件-源代码-V1.0.0.pdf`。

### 2.4 导出后的检查项

- [ ] 页眉软件名称与申请表完全一致；
- [ ] 版本号统一为 V1.0.0；
- [ ] 页码从 1 到 60 连续；
- [ ] 每页 50 行，无大面积空白；
- [ ] 首页从 `app.js` 或 `app.json` 开始，最后一页为业务代码；
- [ ] 代码中无第三方付费组件、无侵权素材（词库授权已单独确认）；
- [ ] PDF 清晰可读，无乱码（中文字体正常嵌入）。

> 若审核机构要求「每页 50 行」指正文行数不含页眉，当前版式已满足；
> 脚本已按显示宽度自动折行，避免超长代码行把一页撑成两页。
> 如打印后仍出现分页偏移，可将 CSS 中 `pre` 的 `font-size` 由 8pt 调为 7.5pt。

### 软件功能简介（可直接复制，约 300 字）

> 词灵岛四六级英语学习软件是一款面向大学英语四、六级备考的微信小程序。
> 软件以卡通手绘风格构建「词灵岛」学习场景，内置 3924 个四六级词条，
> 提供词书学习、基于间隔重复算法的智能复习、词根拼图、影子跟读、
> 阅读闯关、情景对话、写作诊断、错题病历、模拟考场与学习统计等功能。
> 软件创新性地将学习行为与 5 只原创伙伴的养成、知识花园、剧情闯关结合：
> 学习者每学一个单词即可获得词力，推动当前伙伴进化；掌握单词会让花园开花；
> 累计词汇量可解锁新伙伴与六章主线剧情。所有学习数据保存在本机，
> 无需注册账号，核心功能离线可用，适合学生利用碎片时间备考使用。
