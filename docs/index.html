快速开始

  • 克隆仓库：git clone https://github.com/lwahaha131211/cet-word-island.git
  • 打开微信开发者工具 → 导入项目 → 选择 cet-word-island-miniprogram 目录
  • 修改 project.config.json 中的 AppID 为你自己的小程序账号
  • 无需后端，所有数据保存在本机 Storage，首次打开即可完整体验

六大特色

  • 多伙伴养成：5 只原创伙伴，各 5 段进化，最终分支由词根/词性结构决定
  • 词根拼图工坊：把单词拆成词根碎片混入干扰项，按构词顺序拼回
  • 知识花园：单词熟练度达 4 级才开花，花色由单词 ID 哈希决定
  • 剧情章节：6 个章节，词汇量是解锁故事的唯一钥匙
  • 卡通手绘风：深棕描边 + 奶油底色 + 硬阴影，全部插图 CSS 绘制
  • 无后端依赖：本地数据层，离线完整可用
